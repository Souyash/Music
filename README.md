# Melodia Music Academy

An editorial, conservatory music academy web application featuring responsive design, interactive course filtering, trial booking modal, and smooth animations.

## Features
- **Modern Conservatory Design**: Curated layout using Tailwind CSS, Playfair Display & Plus Jakarta Sans typography.
- **Scroll & Micro Animations**: Smooth entrance animations (`IntersectionObserver`), live soundwave equalizer bars, and ambient floating music notes.
- **Interactive Disciplines Filter**: Real-time filtering for Piano & Keys, Strings, Vocals, and Percussion.
- **Trial Lesson Booking Modal**: Interactive appointment booking form with instant confirmation.
- **Responsive Navigation**: Mobile slide-out drawer navigation and desktop header.

## Quick Start
Open `index.html` in any modern web browser or run a simple local web server:

```bash
# Python 3
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
